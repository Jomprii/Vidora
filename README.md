# Vidora

Vidora is an ad-free local video player built with Expo. Choose videos from your
device, search your current library, and play a video with native playback
controls. Videos are not uploaded or sent to an ad network.

## Get started

```bash
npm install
npx expo start
```

Open the project in an Android or iOS development build to try local video
selection and playback. The document picker copies selected files to its cache
so the player can read them immediately.
